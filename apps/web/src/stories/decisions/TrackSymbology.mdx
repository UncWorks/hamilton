# Track symbology — decisions

The COP's track symbol, as decided. Production code: **`src/components/symbol`** (`TrackSymbol`, `TrackSymbolWithTooltip`,
`DeclutterStack`, `trackSymbolSvg` / `trackSymbolDataUrl`) with **`src/lib/track-sidc.ts`** (`toSidc2525E`,
`toSidc2525C`, `toCotType`) and **`src/lib/link-trust-rating.ts`** (rating names, J split). Manual: **FM 1-02 / MCRP 5-12A,
"Operational Terms and Graphics" (21 Sep 2004)**; page numbers are the manual's own. Bench numbers come from the At-a-Glance
protocol (glance-symbology-research.md §5), measured in the browser on the production primitives when the decision was
made; they are recorded as static tables on this page (see **Evidence record** below).
The live renderers draw it: CesiumSpine as billboards (the `trackSymbolSvg` image), MapSpine as an SVG overlay
(`TrackSymbolG`), both with the production `DeclutterStack` and the rating tooltip — see
[COP: live spine](?path=/story/decisions-track-symbology--cop-live-spine).

## 1 · Base symbol: V1 filled frames + V4 unit labels

**Choice.** Table 4-1 frames (p 4-3) filled with the Table 4-3 hues (p 4-4) at dark-map luminance (friend #0091c0,
hostile #f00000, neutral #00b000, unknown #dcd900), frame line in `--sym-ink`, enlarged Table 5-3 icons in #06090d (FA
cannonball r 25, COLT/FIST dot r 20). From V4, only the label behaviour: T left of the frame (Fig 4-2, p 4-5), mono 400,
never smaller than a 24 px symbol's label (10 px). Below 28 px, the echelon (Table 5-6, p 5-33) and every amplifier
except T are hidden. V4's heavier strokes and 24 px box floor are **not** taken.

**Rationale.** Fill colour is a guiding feature that is redundant with frame shape, and MIL-STD-1472H §5.17.25.15 prefers
filled symbols. ¶4-10 (p 4-10) requires symbols that are "easily distinguishable", including without colour. FINAL scores
T1 0.81 max / friend–hostile 0.62 (pass ≤ 0.85 / ≤ 0.70), and T4 100 % affiliation and function at 16, 24 and 32 px.
The n-gons fail at 0.97.

**Evidence.** [Matrix](?path=/story/decisions-track-symbology--matrix) · T1 and T4 in the
[bench scores](#final-symbol-bench-scores) below · V1 and V4 under [Rejected options](#rejected-options-history).

## 2 · Trust cue: side gauge + J, outside the frame

**Choice.** The Hamilton link-trust overlay is a 3 px side gauge directly right of the frame. Its fill height is the
score, in the trust colour. J (evaluation rating) is drawn as text right of the gauge, so no field moves when J appears.
Neither changes the frame or the fill. There is no circular halo, no frame-following outline and no blink. The gauge is non-doctrinal: it
is labelled in the legend (¶4-5, p 4-4) and is never exported.

**Rationale.** A circle is the friendly equipment frame (Table 4-1, p 4-3), and the variable-rate pulse conflicts with
MIL-STD-1472H §5.17.27. On the bench, the halo raises silhouette similarity by +0.72 (T2, V0) and the outline by
+0.10 (V3, V4). The fail line is +0.05. The gauge adds +0.01. J is a doctrinal field (Table 4-4, p 4-6).

**Evidence.** [Trust bands](?path=/story/decisions-track-symbology--trust-bands) · T2 in the
[bench scores](#final-symbol-bench-scores) below · the halo and the V3 outline under [Rejected options](#rejected-options-history).

## 3 · Rating names, hover breakdown, J split

**Choice.** The rating names stay NOMINAL / WATCH / DEGRADED / UNRELIABLE / STALE, and hovering or focusing a symbol
opens the factor breakdown, now the production `RatingTooltip`. J is split into two axes:

- the score sets the **reliability letter**: B / C / D / E at ≥ 0.85, ≥ 0.60, ≥ 0.30 and below;
- corroboration sets the **credibility digit**: 1 when confirmed on an alternate channel or by a second sensor, otherwise
  today's 2 / 3 / 4 / 5;
- STALE becomes **F6**, with AR = NRT;
- the S2 can override J with a reason (`jOverride` in the fixtures). The override is shown and exported, and the
  automatic value is kept in the tooltip;
- an algorithm never emits "A".

**Rationale.** Table 4-4 (p 4-6) treats reliability and credibility as independent axes. The B2 / C3 / D4 / E5 diagonal
conflated them (decision-workflow assessment §6, item 2). HS-14 keeps J an S2 product. The names avoid every reserved
2525 / FM 1-02.2 term. Unit tests cover the split, F6, never-A and override validation (`link-trust-rating.test.ts`).

**Evidence.** [Rating tooltip](?path=/story/decisions-track-symbology--rating-tooltip) ·
[Trust bands](?path=/story/decisions-track-symbology--trust-bands). The tooltip started as Option B′'s and is now production.

## 4 · Standards: MCRP 5-12A drawing, 2525E stored, 2525B/C + CoT exported

**Choice.** Symbols are drawn to FM 1-02 / MCRP 5-12A (2004). The 20-digit 2525E SIDC is stored (`toSidc2525E`). For
ATAK, export the 15-character 2525B/C letter SIDC (`toSidc2525C`) and the CoT type (`toCotType`). Mapping:

- FA battery: 130300 / UCF--- / a-f-G-U-C-F
- COLT/FIST: 130400 / UCFTCD
- TA radar: 130300 + modifier 50 / UCFTR-. Not 130302, which is 2525D only.
- Recon, motorized: 121303 / UCRVM-
- Air defense: 130100 / UCD---
- EW jamming: 150504 / UUMSEJ

**Rationale.** MCRP 5-12A is 2525B-era (Preface p vi), so its CoT type follows directly from the 2525B function code,
while 2525E is the current storage standard. The codes come from glance-symbology-research.md §2.1 and pass milsymbol 3.0.4
`isValid()`. `hostile_ew_1` is drawn as EW jamming (p 5-18), not as an air-defense dome.

**Evidence.** [Export: SIDC / CoT + billboard image](?path=/story/decisions-track-symbology--export) ·
[MCRP 5-12A vs 2525E](#mcrp-5-12a-vs-mil-std-2525e) and [Unverified](#unverified--not-found) below.

## 5 · TA-radar glyph enlarged (T7 condition iii)

**Choice.** The FA target-acquisition radar glyph (dot + radar, Table 5-3, p 5-13) is enlarged inside the frame. Icon
enlargement within the frame is permitted (2525D §5.3.1.2).

- Friend and neutral frames: 1.45×, re-centred vertically, radar stroke 1.5× the frame stroke.
- Hostile diamond: 1.12×. Unknown quatrefoil: 1.15×. Beyond that, the radar arm crosses the frame.

**Before / after.** T7 (iii) asks how quickly a friendly FA battery stands out among friendly TA radars. Minimum R over
N 8 / 16 / 32, pass ≥ 2:

| Glyph | R at N 8 | R at N 16 | R at N 32 | Result |
|---|---|---|---|---|
| Before: V1, doctrinal size | 1.11 | 1.29 | 1.14 | Fail |
| Iteration 1: 1.45×, stroke ×1.25 | 1.99 | 2.15 | 1.95 | Fail |
| Iteration 2 (shipped): 1.45×, re-centred, stroke ×1.5 | 2.12 | 2.29 | 2.07 | Pass |
| REF (calibration) | — | — | — | 2.17 |

The pass margin is thin. T7 tests the friend frame only, and the hostile and unknown glyphs, which cannot grow as far, are
not tested. The T7 threshold is provisional (research §5.3), and REF itself only reaches 2.17. If the threshold is
recalibrated, it should be set relative to REF, for example R ≥ 0.9 × R(REF), rather than as an absolute 2.

**Evidence.** The before / after table above, measured with the T7 (iii) bench when the decision was made.

## 6 · Clustering: E, doctrinal declutter

**Choice.** When three or more symbols overlap within 1.5·s, they are drawn as a bracketed stack with one locator line to
the true location, hostile first (¶5-8, Fig 5-6, pp 5-41/5-42). If the stack still collides, it shows three frames and
"+n", a labelled Hamilton convention. Only the symbol-side pieces are built here: `DeclutterStack`, `StackBracket`,
`OverflowCount`, `stackOrder` and `stackGeometry`. Deciding when tracks collide belongs to the map renderers.

**Rationale.** E addresses the overlap penalty reported by Fletcher et al. (2011), and MIL-STD-1472H §5.17.22.4.4 asks for
declutter controls. The stack is a doctrinal construct, unlike a bespoke cluster bubble.

**Evidence.** [Declutter stack](?path=/story/decisions-track-symbology--declutter) ·
[COP: live spine](?path=/story/decisions-track-symbology--cop-live-spine) ·
COP/CesiumSpine and COP/MapSpine › *Dense* and *Zoomed out*.

## Evidence record

### Protocol

glance-symbology-research.md §5. Every cell was drawn on a 2s × 2s canvas at DPR 1 from the same primitives as the SVG,
over the map colour #06090d. T1 and T2 use silhouette alpha; T3 and T4 use Rec.709 linear luminance. T5 reruns on CIE L*.
T6 reruns on luminance after Machado 2009 (severity 1.0, linear RGB) deuteranopia and protanopia.

- **T1** soft IoU (Σmin / Σmax) after Gaussian σ 1 and 2 px, 24 px, overlay off, max over the five functions.
- **T2** T1 (σ 1) with the overlay on at trust 0.45 and 0.20 vs off. No pair may rise by more than 0.05.
- **T3** function distance D on the blurred icon signal, 32 px, min over frames. Must be ≥ REF and ≥ 1.5× V0.
- **T4** max-NCC classification of 16 sub-pixel offsets with σ 0.02 noise against ≥ 128 px templates.
- **T5** contrast ≥ 3:1 (WCAG 1.4.11) for frame vs map, icon vs fill and trust cue vs map. **T6** ΔE76 ≥ 20 for
  colour-coded pairs, or a redundant non-colour code.
- **T7** salience ratio R on blurred CIE L*a*b*, 24 px, N 8 / 16 / 32, distractors at random ¼-px offsets. R ≥ 2.
- **T8** human search slope (RT = a + b·N), timed by hand.

REF was a reconstruction of milsymbol default sizes with 2525C light fills (milsymbol is not a dependency). The T3, T6 and
T7 thresholds are provisional (research §5.3), calibrated only by REF passing and V0 failing.

### MCRP 5-12A vs MIL-STD-2525E

| Topic | FM 1-02 / MCRP 5-12A (2004) | MIL-STD-2525E | Consequence |
|---|---|---|---|
| Base standard | STANAG 2019 / APP-6A; "complies with ... 2525" (Preface p vi; p 4-1) | 2525E is "the single standard" | Symbol vocabulary is 2525B-era |
| SIDC | 2525B 15-character letter codes; the manual prints none | 20-digit numeric | Store 2525E numeric; export letter SIDC + CoT. 130302 has no 2525E equivalent |
| ATAK / CoT | CoT type derives from the 2525B function code | Needs a lookup table | MCRP alignment makes CoT export direct |
| Assumed friend / suspect | Base frame + "?" (Table 4-1 p 4-3) | Dashed variants | A dash means only planned / suspected status (p 4-4): never dash for trust |
| Colour values | Names only; non-default colours need a legend (p 4-4) | RGB tables | Trust colours must appear in the legend |
| Status / condition | K = combat effectiveness 1–4 (p 4-7); no condition bar | AL operational-condition bar | No bars under the frame for trust in either standard |
| Evaluation rating | J = A–F / 1–6 (p 4-6) | Same J field | J split (decision 3) |
| Echelon | Ø • •• ••• I II (Table 5-6 p 5-33) | Same glyphs; numeric codes | Team = Ø (a dot is a squad) |
| FA TA radar | Dot + radar (p 5-13) | 130300 + modifier 50 | Same look, different code path |
| EW | Jamming = "EW" + sawtooth (p 5-18) | Intelligence 1505xx | `hostile_ew_1` renders as EW jamming, not an air-defense dome |
| Declutter | Offset line; bracketed stacks (pp 5-41/42) | Offset indicator retained | Doctrinal aggregation exists (decision 6) |
| Combat-effectiveness colours | Green ≥ 85 %, amber 70–84, red 50–69, black < 50 (p D-2) | — | Trust in amber / red can read as unit strength: keep trust off the fill |

### Unverified / not found

- Change 1 date of the MCRP copy (not found in the front matter).
- Fletcher et al. 2011 (DSTO-TR-2604) symbol sizes and slopes: abstract only.
- NSWCDD 24′ default symbol size: search snippet only.
- DRDC (ADA509467) and McFadden (ADA477198) reports: not read.
- Not found: Kerr / Fisher 2525 recognition studies, an ARL legibility report, a NATO HFM symbology study, a doctrinal
  rationale for the four frame shapes.
- Letter SIDCs come from 2525C / milsymbol 3.0.4 tables (all pass `isValid()`); the 2525B and 2525E texts were not consulted.
- REF is a reconstruction of milsymbol defaults, not milsymbol output.

## Rejected options (history)

These explorations led to the decisions above. Their stories and support code were removed from Storybook once the
decided symbol shipped; this section is the record of what they were and why they lost.

- **V0, the original Branding §5.2 n-gons.** Side count = sensor type, enemy rotated 45°, opacity = trust and a pulsing
  circular halo below the TSS minimum. Fails T1 (0.97), T2 (+0.72 from the halo) and T7 (iv). A circle is the friendly
  equipment frame, and the variable-rate pulse conflicts with MIL-STD-1472H §5.17.27.
- **Halo treatments** (spec pulse, sonar ping, breathing glow, static ring). All draw a circle over the amplifier slots;
  dropped with decision 2.
- **Options A / B / C / B′.** A: APP-6 palette-tuned frames. B: monochrome frames with trust on the frame (dash, condition
  bar, damaged slash, raw score in J), each of which collides with an existing 2525 meaning. C: a hybrid bespoke
  scheme. B′ fixed B's collisions and introduced the rating tooltip, which is now production.
- **At-a-Glance variants V1–V4.** V1 (filled doctrinal frames) became the base symbol. V2 (unfilled monochrome) lost the
  colour guiding feature. V3 (frame-following trust outline, +0.10 on T2) and V4 (heavier strokes, 24 px floor) were
  not taken, except V4's label treatment.
