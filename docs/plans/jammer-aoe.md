# Plan: jammer area-of-effect (AoE) estimation and display

**Status:** plan + Storybook previews only. No engine, simulator or contract code is changed by this branch.
**Base:** `origin/review/combined` @ `d6b9e5f` (PR #4 TSS row + PR #5 offline basemap on #3/#2).
**Inputs:** the AoE design (`jammer-aoe-design.md`, with its worked-example script), the jamming inventory (`ua-jamming-inventory.md`) and its independent verification (`ua-jamming-verification.md`, grade B−). Where they disagree, **the verification wins**. Every physical parameter below is tagged with its provenance (§7.1).
**Previews:** Storybook → **Previews/Jammer AoE** (`apps/web/src/stories/previews/JammerAoe.stories.tsx`). They use real components and geometry generated by `scripts/aoe-preview/gen_fixtures.py`.

## 1. Goal and non-goals

**Goal.** The C2 should never show where a jammer *is* when it does not know. Today it does: a hard-coded `JAMMER_LOCATION`, a fabricated bearing line from B and a fixed 120 m ring. Replace these with an honest, deterministic estimate built from friendly observations only. The estimate is:

- a **probability-graded area of effect per receiver class**, with a 50% contour (dashed outline) and a 90% contour (fill and edge);
- a **90% emitter region**, drawn as the MCRP 5-12A **NAI** graphic, dashed;
- a **status-1 (dashed) hostile EW symbol**, shown only when the estimate earns it: a 90% region of 25 km² or less, or at least 2 bearings crossing at 30° or more;
- an **advisory geometry term** on the TSS mission row. Reliability stays the hard gate.

**MVP scope.** Everything here comes from the design, re-parameterised with verified numbers.
- A soft **set-based grid estimator**. This is the Bayesian grid with a step/probit likelihood. It uses a fixed 250 m ENU grid, a fixed 3 × 3 EIRP × mast hypothesis set per method, σ = 6 dB, closed-form Φ and ordered summation.
- A **link-budget radius band per method × receiver class**: two-ray plus radio horizon, receiver thresholds from `receivers.json`.
- The **engine computes the polygons** (marching squares plus simplification to ≤ 64 vertices). The web only draws them, so no new web dependencies are needed (NFR-07).
- Receiver classes: civil GNSS and military GNSS (DAGR-class). UHF and FPV layers exist in the contract, but only methods whose bands cover them produce them.

**Non-goals for the MVP.**
- Bearings and DF are not in the MVP. The 1:35 bearings beat is an optional v3 slice.
- No terrain or DEM, no ITM.
- No graded C/N0 likelihood (v2). No sector or wedge fitting (v2; see §7, decision D8).
- No spoofing layer, no CoT `u-d-f` export (v2). No H3 or heat surface.
- No ML. The R14 discipline holds: identical input gives byte-identical output. The R14 answer: *"a fixed-grid evidence map; each cell's score is a product of published link-budget tests; no training, no learned weights."*

## 3. Contract sketches

### 3.1 Telemetry v2 (`telemetry/{source_id}/raw`)

```ts
export const RxClassSchema = z.enum(['gnss_civil', 'gnss_mil', 'gnss_mil_crpa', 'uhf_comms', 'fpv_link']);
export const TelemetryPayloadSchema = z.object({
  schema: z.literal('telemetry/2').optional(),          // absent = v1
  source_id: z.string().min(1),
  lat: z.number().min(-90).max(90),
  lon: z.number().min(-180).max(180),
  inter_arrival_seconds: z.number().nonnegative(),
  crc_error_rate: z.number().min(0).max(1),
  duplicate_rate: z.number().min(0).max(1),
  rx_class: RxClassSchema.optional(),
  gnss_cn0_dbhz: z.number().min(0).max(60).optional(),  // mean of top-4 SVs
  gnss_agc: z.number().min(0).max(1).optional(),        // normalised
  gnss_jam_ind: z.number().int().min(0).max(255).optional(), // u-blox style
  gnss_fix: z.enum(['3d', '2d', 'none']).optional(),
  snr_db: z.number().optional(),
  noise_floor_dbm: z.number().optional(),
  rlq: z.number().min(0).max(100).optional(),
  rf: RfObservationSchema.nullable().optional(),        // effective_range_km optional + deprecated
```

## 5. Test plan

### 5.1 Estimator vs hidden truth (`crates/estimator/tests/golden.rs`; same numbers in the preview Evaluation story)

The scenario is the verified Pole-21E envelope; truth is 300 W EIRP / 10 m / 125° west-facing, 9.6 km east of B. Measured by the preview generator on the same model:

| Beat / evidence | Truth in 90% region | 90% region | Mode error | Civil AoE IoU vs true (footprint) | Symbol |
|---|---|---|---|---|---|
| 1:15, 8 units binary | yes | 906 km² | 27.4 km | 0.14 (0.46) | no |
| 1:35, 8 graded + 2 bearings (B, H) | yes | 9 km² | 0.5 km | 0.40 (0.58) | yes |
| 1:50, + B healthy 5 km west | yes | 809 km² | 27.4 km | 0.13 (0.49) | no |

Assertions:
- truth ∈ 90% region at every beat;
- area90 ≤ 1.1 × the recorded golden value;
- symbol suppressed whenever area90 > 25 km² and there are fewer than 2 bearings;
- with bearings, mode error < 1.5 km;
- **AoE IoU measured inside the evidence footprint** ≥ 0.4.

The design's "IoU ≥ 0.6 with 8 units" target is **not met** by binary evidence (0.46). Either adopt 0.4 or require graded evidence (D7). A performance test checks < 50 ms per update for 20k cells × 9 hypotheses × 10 units.

### 5.2 No-leak

- `comms-sim/tests/test_truth_isolation.py`: no truth value appears on any topic body over a full run.
- Engine test: the estimate payload never contains the truth position. Allow it only when the estimator found it, which means more than 1 km from the truth for binary evidence.
- Web lint rule (grep in CI): `JAMMER_LOCATION` and `AOE_TRUTH` must not be imported outside `stories/**` Evaluation stories.

### 5.3 Contract round-trips

TS fixture → JSON → Rust `serde` → JSON → zod parse must be equal, for both the telemetry v2 and estimate payloads. `deny_unknown_fields` rejects a v3 field. The v1 telemetry still parses.

### 7.1 Parameter provenance (replaces "pending verification")

**What changed against the design.** The design's 20 W / 15 m omni emitter and its 5–80 W hypotheses are **superseded**. With the verified Pole-21E envelope:
- the 1:15 NAI grows from ~270 to **~906 km²**;
- the mode error grows from ~9 to **~27 km**, because the 60 m / 1 kW hypothesis pulls the mode toward a far-east lobe;
- the 50% civil AoE is **~1660 km²**;
- E becomes degraded (4 degraded / 4 healthy instead of 3 / 5);
- P(denied) at OBS B rises to 0.96, so the advisory reads **90%**.

Without the standoff prior the NAI is ~1030 km² and the 50% AoE ~2140 km².
